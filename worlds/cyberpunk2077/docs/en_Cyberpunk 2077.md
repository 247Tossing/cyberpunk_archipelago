# Cyberpunk 2077

An Archipelago randomizer for Cyberpunk 2077. Story and side content, gigs, tarot cards, cyberpsycho sightings, NCPD hustles, minor quests, and optional vendor-stock checks can hold items from the multiworld.

Progression is carried by district access tokens and, when weapon restrictions are set to pass-gated, weapon pass items. Optional trap items, eddies, and quickhacks fill the rest of the pool.

Phantom Liberty content is optional. Vendor Sanity is optional and split by vendor type: ripperdocs, weapon vendors, clothing vendors, melee vendors, and netrunners.

Connect from the Cyber Engine Tweaks overlay after installing the game mod. The setup guide covers install steps and the connection fields.
